# Teacher Guide: IELTS Academic Task 1 Interactive Studio

## Overview
This web application is designed to help IELTS instructors and students interactively explore, modify, and analyze standard Academic Task 1 visual data prompts (Line Graphs, Bar Charts, Pie Charts, and Data Tables).

## Key Features for Classroom Teaching
1. **Curriculum Exercise Library:** Loaded with 40 distinct, authentic IELTS practice datasets stored as modular JSON files across `line`, `bar`, `pie`, and `table` categories.
2. **Dynamic Exercise Selector:** Use the "Exercises" button in the top navigation bar to pull up a random, full-fledged IELTS exercise for the selected graph category.
3. **Live Prompt Customization:** Teachers can quickly edit prompt text, series data, or table cells to customize practice materials on the fly.
4. **Zero Hosting Cost:** Built with static web standards (HTML5, Tailwind CSS, Chart.js, Vanilla JavaScript), fully compatible with GitHub Pages or any static Web Server.
