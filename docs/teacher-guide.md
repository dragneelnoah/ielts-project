# Teacher Guide: IELTS Academic Task 1 Interactive Studio

## Overview
This web application is designed to help IELTS instructors and students interactively explore, modify, and analyze standard Academic Task 1 visual data prompts (Line Graphs, Bar Charts, Pie Charts, and Data Tables).

## Key Features for Classroom Teaching
1. **Live Prompt Customization:** Teachers can quickly edit the prompt title, description, and underlying data values to create bespoke practice material for lessons.
2. **Instant Randomization:** Use the "Randomize Prompt" button to generate fresh numbers and categories on the fly, eliminating student memorization.
3. **JSON Power Mode:** Advanced students can inspect and manipulate raw JSON data structures, reinforcing data literacy.
4. **Zero Hosting Cost:** Built with static web standards (HTML5, Tailwind CSS, Chart.js, Vanilla JavaScript), fully compatible with GitHub Pages.
